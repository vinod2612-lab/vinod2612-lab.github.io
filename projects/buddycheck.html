Flagship Project 02 · Data Quality & Reconciliation

BuddyCheck V8

A Python data-audit/reporting workflow that compares Excel Feature/Model information with XML and extends validation into country coverage, GEO rules, availability links, GA dates, and structured difference reporting.

Role: Project Lead & Developer
Identified the high-effort manual Buddy Check validation workflow and initiated the automation project. Designed and developed the data comparison, normalization, GEO/country validation, availability checking, GA-date validation, and audit-report generation workflows.

Case studyProblemSolutionBefore / AfterImpactValidationChallengesEvidence

Problem

Manual Buddy Check required comparing multiple data representations and validation dimensions.

The automation addresses a data-consistency task where Excel Feature/Model values are compared with XML while country, GEO, availability, and GA-date rules can also require validation and discrepancy reporting.

Solution

Normalize the sources, compare them systematically, and produce reviewable evidence.

Feature & Model fields

Map Excel fields to XML tags, normalize selected semantic variants, and write differences.

Country coverage

Resolve country mappings and compare expected coverage with XML country sets.

GEO rules

Expand configured region/group restrictions where supporting General Area data exists.

Availability

Build availability/relator indexes and evaluate linked country/date coverage.

GA dates

Use announcement/default/override date information in GA validation workflows.

Audit output

Create and style a multi-sheet Excel workbook for discrepancies and supporting summaries.

Technical Challenges

Reliable comparison requires resolving representation differences, not just checking raw strings.

  • Mapping Excel template fields to XML tags and normalizing selected business representations.
  • Combining different XML parsing approaches for field access versus country/availability indexing.
  • Resolving country names/codes and optional GEO group expansion without exposing internal source data.
  • Separating feature/model mismatches from country/availability and GA-date validation outputs.
  • Generating a workbook that supports human review rather than only printing differences to the console.

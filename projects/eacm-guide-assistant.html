Flagship Project 03 · AI-enabled Internal Tooling

EACM Guide Assistant

A grounded internal knowledge assistant that combines deterministic process/domain routing, BM25 retrieval, parent-context expansion, IBM watsonx.ai generation, structured output, and citation validation behind a Django web interface.

Role: Project Lead & Developer
Identified the difficulty of reliably retrieving procedural information from enterprise guides and led development of a grounded knowledge assistant covering ingestion, deterministic routing, retrieval, context handling, AI generation, grounding validation, testing, and web delivery.

Case studyProblemSolutionArchitectureImpactValidationChallengesEvidence

Problem

Retrieval quality matters when users depend on procedural guidance.

The project addresses wrong-guide / wrong-domain retrieval and reliable access to approved process documentation. Deterministic process classification and hard applicability filtering are used before BM25 retrieval to reduce domain mistakes.

Solution

A grounded retrieval pipeline with explicit controls before and after generation.

Document ingestion

Convert and normalize PDF, DOCX, HTML, and Markdown guide content into structured retrieval artifacts.

Process / domain routing

Classify and route questions before retrieval; request clarification when needed.

BM25 retrieval

Retrieve lexical candidates from approved document scope without a vector database.

Context expansion

Restore parent context, citations, provenance, and context budgets around retrieved chunks.

watsonx.ai generation

Generate structured answer blocks through a provider boundary.

Grounding validation

Strictly parse structured output and validate citation IDs against the supplied prompt/context before returning a public response.

Technical Challenges

Grounded AI is more than sending retrieved text to an LLM.

  • Preventing wrong-domain retrieval before generation rather than trying to fix it only in the prompt.
  • Restoring enough parent context to answer correctly without overflowing context budgets.
  • Maintaining source provenance from ingestion through retrieval, context packaging, generation, and browser rendering.
  • Rejecting malformed or unsupported structured output rather than silently displaying it.
  • Separating model generation from deterministic test behavior through a provider abstraction.

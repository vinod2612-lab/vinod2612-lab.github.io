Flagship Project 01 · Desktop Automation

EACM Selection Bot

A deterministic Python automation system for reading Excel Machine Type / Model / Feature Code records, locating the exact EACM Product Structure rows, selecting them, reconciling the result, and producing an auditable run record.

Role: Project Lead & Sole Developer
Identified the repetitive manual feature-selection workflow, designed the automation and reconciliation approach, and built the end-to-end Python solution from Excel ingestion through EACM selection, verification, logging, and audit reporting.

Case studyProblemSolutionArchitectureImpactValidationChallengesEvidence

Problem

Manual grid selection was repetitive and hard to verify at scale.

The documented workflow requires a Data Specialist to compare RFA Excel records with EACM and select feature-code rows in the Product Structure grid. The automation targets the repetitive portions while preserving exact identity and auditability.

Solution

A deterministic selection pipeline with reconciliation built in.

1. Ingest

Read the RFA workbook and discover the required Feature data columns.

2. Normalize

Split MTM into Machine Type and Model, normalize identifiers, validate rows, and detect duplicates.

3. Discover

Focus EACM, open Product Structure, scan the grid, and build composite row identities.

4. Select

Use deterministic keyboard-driven selection rather than AI-based matching.

5. Reconcile

Read selected row identities from the clipboard and compare them against the expected selection set.

6. Audit

Write run logs, final status buckets, and a 19-column Excel audit workbook.

Technical Challenges

Automating a stateful legacy desktop grid requires stronger verification than a simple click script.

  • Preserving Machine Type / Model / Feature identity so same-feature collisions across models do not become false matches.
  • Scanning a desktop grid without a modern API and detecting row/bottom boundaries safely.
  • Maintaining deterministic selection state across keyboard and clipboard operations.
  • Reconciling what the automation intended to select against what EACM actually reports as selected.
  • Producing logs and audit output that support troubleshooting and review.

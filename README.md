# Vinod Kumar N — Recruiter-focused Portfolio

Static HTML/CSS/JavaScript portfolio for Python Automation & Enterprise Data/Tooling roles.

## Deploy

Upload the contents of this folder to the root of the `vinod2612-lab.github.io` repository and publish from the `main` branch / root folder.

No build step, package manager, backend, or JavaScript framework is required.

## Primary files

- `index.html` — recruiter-first homepage
- `projects/eacm-selection-bot.html` — flagship automation case study
- `projects/buddycheck.html` — data-quality/reconciliation case study
- `projects/eacm-guide-assistant.html` — grounded AI-enabled internal-tooling case study
- `css/style.css` — shared responsive styles
- `js/script.js` — theme, navigation, reveal behavior
- `assets/Vinod_Kumar_N_Resume.pdf` — primary resume download
- `assets/Vinod_Kumar_N_Resume.docx` — secondary resume format
- `assets/og-card.png`, `assets/favicon.svg` — social/SEO assets
- `sitemap.xml`, `robots.txt` — search-engine support
- `PORTFOLIO_HANDOFF.md` — implementation summary and recommended evidence assets
- `QA_REPORT.md` — automated technical QA summary
